# WhereNow Activity Diagram

本文件補充 WhereNow 的主要活動流程，協助說明使用者如何從登入、管理地點、建立回憶，到使用情侶共享與隨機推薦功能。

## 1. 使用者登入與進入首頁

```mermaid
flowchart TD
    A["進入 WhereNow"] --> B["顯示登入頁"]
    B --> C["輸入帳號、密碼與 CAPTCHA"]
    C --> D{"驗證是否成功"}
    D -- "否" --> E["顯示錯誤訊息"]
    E --> B
    D -- "是" --> F["建立登入狀態"]
    F --> G["進入首頁"]
```

流程說明：

1. 使用者開啟系統時，若尚未登入會導向登入頁。
2. 登入頁提供帳號密碼與 CAPTCHA 驗證。
3. 驗證成功後進入首頁，驗證失敗則回到登入頁並提示錯誤。

## 2. 新增地點流程

```mermaid
flowchart TD
    A["進入新增地點頁"] --> B["填寫分類、名稱、地區、地址、預算與備註"]
    B --> C["上傳地點照片"]
    C --> D["選擇公開或與情侶共享"]
    D --> E{"表單驗證通過"}
    E -- "否" --> F["回到表單並顯示錯誤"]
    F --> B
    E -- "是" --> G["儲存 Place"]
    G --> H["返回地點列表"]
```

流程說明：

1. 使用者可建立地點並選擇分類。
2. 可設定地點是否公開，或是否與另一半共享。
3. 系統驗證成功後將資料寫入資料庫。

## 3. 新增回憶流程

```mermaid
flowchart TD
    A["進入新增回憶頁"] --> B["選擇關聯地點"]
    B --> C["填寫心得、日期與評分"]
    C --> D["上傳一張或多張照片"]
    D --> E["設定公開或情侶共享"]
    E --> F{"表單驗證通過"}
    F -- "否" --> G["顯示錯誤並重新填寫"]
    G --> B
    F -- "是" --> H["儲存 Memory 與 MemoryPhoto"]
    H --> I["返回回憶列表"]
```

流程說明：

1. 回憶需連結到一個既有地點。
2. 使用者可補充心得、照片與分享設定。
3. 系統會同時儲存回憶主資料與照片資料。

## 4. 情侶邀請與共享流程

```mermaid
flowchart TD
    A["使用者送出情侶邀請"] --> B["對方收到邀請"]
    B --> C{"對方是否接受"}
    C -- "拒絕" --> D["邀請結束"]
    C -- "接受" --> E["建立 CoupleRelationship"]
    E --> F["雙方可查看共享地點與共享回憶"]
    F --> G{"是否解除關係"}
    G -- "否" --> F
    G -- "是" --> H["關係結束"]
```

流程說明：

1. 使用者可邀請另一位使用者建立情侶關係。
2. 成功建立關係後，雙方可看到標記為共享的地點與回憶。
3. 使用者可解除關係。

## 5. 隨機推薦流程

```mermaid
flowchart TD
    A["進入隨機推薦頁"] --> B["選擇分類或篩選條件"]
    B --> C["系統查詢符合條件的地點"]
    C --> D{"是否有符合地點"}
    D -- "否" --> E["顯示無結果訊息"]
    D -- "是" --> F["隨機抽出一筆地點"]
    F --> G["顯示推薦結果"]
    G --> H["寫入 RandomPickHistory"]
```

流程說明：

1. 使用者可依分類或條件進行抽選。
2. 若查無地點，系統提示無結果。
3. 若成功抽出地點，系統會保留抽選紀錄。
